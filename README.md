# 대타구함

카카오톡에 흩어진 대타 요청을 요청, 지원, 승인, 근무표 반영까지 연결하는 교대 관리 서비스입니다.

> 현재 공개 버전은 샘플 데이터로 동작하는 인터랙티브 HTML 프로토타입입니다. API와 데이터베이스는 설계 문서로 제공하며, 서버 연동은 후속 구현 예정입니다.

## 문서

- `docs/openapi.yml`: OpenAPI 명세
- `docs/database.dbml`: 데이터 모델
- `docs/overview.pdf`: 서비스 개요서

## 로컬 실행

`web/index.html`을 브라우저에서 열거나 정적 파일 서버로 `web` 디렉터리를 실행합니다.
